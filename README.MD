# Ejercicios de Práctica en JavaScript

Una pequeña colección de ejercicios rápidos y simples para aprender y practicar JavaScript.

## Acerca del proyecto

Este repositorio contiene ejercicios cortos enfocados en mejorar las bases de JavaScript mediante práctica constante.

Los objetivos principales son:
- Practicar sintaxis y lógica
- Aprender conceptos fundamentales de JavaScript
- Experimentar con pequeños desafíos
- Mantener constancia mientras aprendemos

## Temas incluidos

Algunos de los temas que se practican en este repositorio:

- Variables y tipos de datos
- Funciones
- Arrays y objetos
- Bucles
- Condicionales
- Manipulación del DOM
- Características de ES6+
- Algoritmos básicos

## Estructura

Cada carpeta o archivo contiene un ejercicio independiente con su respectiva solución y, en algunos casos, notas adicionales.

Ejemplo:

```bash
/exercises
  ├── variables.js
  ├── loops.js
  ├── arrays.js
  └── dom-events.js
```

## Objetivo

Este repositorio funciona principalmente como un espacio personal de aprendizaje para:
- Seguir mi progreso
- Practicar regularmente
- Mantener organizados pequeños ejemplos de JavaScript

## Cómo usarlo

Clonar el repositorio:

```bash
git clone <url-del-repositorio>
```

Ejecutar cualquier archivo con Node.js:

```bash
node archivo.js
```

## Notas

Los ejercicios son intencionalmente pequeños y simples.  
El enfoque está en aprender, experimentar y practicar de manera constante.
