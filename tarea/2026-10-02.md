# Ejercicio "MenSpam"

### Crear una aplicación de mensajería llamada "MenSpam"

#### Esta aplicación nos debe permitir enviar mensajes a usuarios 

Esta aplicación debe tener una vista principal donde exista un input "destinatario".

El input destinatario es obligatorio. Al cargar destinatario, se debe mostrar la pantalla de "chat" donde se listan todos los mensajes enviados y recibidos con ese destinatario.

En la pantalla de chat, debe haber un input abajo de la lista de los mensajes, para escribir un nuevo mensaje y un btn de "enviar".

a la izquierda de la pantalla, debe haber una lista de todos los chats, al seleccionar otro chat, se debe mostrar la lista de todos los mensajes enviados y recibidos con ese destinatario.

arriba a la izquierda de la pantalla debe haber un btn "inicio" que tenga el logo de la aplicación, donde al clickear nos lleva a la vista principal, para poder cargar un nuevo destinatario.

Si desde la vista principal selecciono un destinatario con el cual ya tenga un historial de mensajes, se me debe redirigir a el chat con ese destinatario.

Se debe distinguir entre mensajes del usuario activo y el destinatario.

Tanto al seleccionar "destinatario" o al escribir un mensaje, deben aparecer botones de "enviar" y se debe realizar la misma acción al presionar enter en un input.

En este proyecto se puede utilizar cualquier tecnología o herramienta a gusto ( html, css, scss, js, ts, tailwind,react, angular, svelte, IA, figma, etc)
