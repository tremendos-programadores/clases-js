# Ejercicio "MVP no afanado"

### Crear una app llamada "MVP no afanado"

#### Esta app debe permitirme "dar de alta" jugadores de fútbol de selecciones, verlos listados y ordenarlos según una categoría de MVP

Para dar de alta un jugador se debe llenar un formulario con los campos:
- Nombre: string
- Edad: number ( sin decimales ) 
- Goles: number ( sin decicmales )
- Regates: number ( sin decicmales )
- Tiros: number ( sin decicmales )
- Ocasiones: number ( sin decicmales )
- Atajadas: number ( sin decicmales )
- Selección: string

El formulario debe tener una acción de "submit" en la cúal se añadirá al jugador a la lista de jugadores de la app y se limpiarán los campos del formulario

Para ordenarlos según categoría de MVP se deberá seleccionar una opción de un desplegable (select/dropdown) donde se listen las siguientes opciones:
- mejor arquero
- máximo asistidor
- máximo goleador
- máximo creador
- mejor sub 23
- máximo MVP

una vez seleccionada la categoría de MVP se mostrará un cuadro con los 10 mejores jugadores de dicha categoría, el formato para mostrar un jugador será: "{puesto}. {nombre} - {selección}". 
Ejemplo "1. Messi - Argentina" 

Para ver a los jugadores listados se deberá crear un cuadro por cada selección, donde se listen sin orden determinado a los jugadores de dicha selección: Ejemplo
[[ Argentina: Messi, Dibu, Julián Álvarez, Enzo Fernandez ] - [ Portugal: Ronaldo ]]

NOTAS:
- Al cambiar de opción en el selector de categoría, se debe recalcular a los mejores jugadores para dicha categoría. Si no tengo categría seleccionada, no se mostrará el cuadro de MVPs.


BONUS: 
- La lista de jugadores deberá persistir en la app en caso de que se recargue la pantalla, se cierre la pestaña/ventana, o se apague el equipo.
- Si no completo todos los campos del formualario, se debe emitir una alerta "faltan completar campos" y NO se debe añadir al jugador a la lista de jugadores, ni limpiar los campos
